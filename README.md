# 🏏 Cricket Score App

A simple, lightweight, and easy-to-use web application for tracking cricket match scores in real-time.

## 🌐 Live Demo

**[👉 Click here to use the app now!](https://kaleidoscopic-rugelach-0aac54.netlify.app/)**

The app is deployed and live on Netlify. No installation needed - just click the link above!

## ✨ Features

- **Live Score Tracking**: Keep track of runs and wickets in real-time
- **Over Counter**: Automatically calculate overs and balls bowled
- **Extra Runs**: Add wide, no-ball, bye, and leg-bye runs
- **Dot Balls**: Record dot balls easily
- **Wicket Management**: Add wickets with a single click
- **Undo Function**: Revert the last action if needed
- **Reset Match**: Start fresh with a new match
- **Live Summary**: View match summary at a glance (e.g., 45/3 in 8.2 overs)
- **Responsive Design**: Works smoothly on desktop, tablet, and mobile devices
- **Dark Theme**: Eye-friendly dark UI for outdoor use

## 🚀 Quick Start

1. Open `index.html` in your browser

   Or serve locally:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## 📋 How to Use

- **Add Runs**: Click on 0, 1, 2, 3, 4, or 6 buttons
- **Add Extras**: Click Wide, No Ball, Bye, or Leg Bye buttons
- **Record Wicket**: Click the "Wicket" button
- **Dot Ball**: Click the "Dot Ball" button to record a ball with no runs
- **Undo**: Revert the last action
- **Reset**: Clear the score and start a new match
